# Security Policy


## Reporting a Vulnerability

We take the security of **openinvento** seriously. If you believe you have found a security vulnerability, please report it responsibly using the **GitHub Security Advisories** feature.

### How to Report

1. Navigate to the **"Security"** tab of the repository.
2. Click on **"Advisories"** in the left sidebar.
3. Click **"Report a vulnerability"** to open a private draft advisory.
4. Provide details of the vulnerability

*Please do not open public GitHub issues for security vulnerabilities.*

Thank you for helping keep **openinvento** safe!
